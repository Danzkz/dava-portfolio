DAVA PORTFOLIO
==============
File:
- index.html
- style.css
- script.js
- assets/profile.jpg

Cara menjalankan:
1. Buka folder ini di VS Code.
2. Klik kanan index.html -> Open with Live Server (jika ada).
3. Atau cukup double-click index.html untuk membuka di browser.

Edit foto:
Ganti assets/profile.jpg dengan foto lain dan gunakan nama file yang sama.

Edit kontak:
Buka index.html lalu ubah email, GitHub, dan LinkedIn pada bagian Contact.
